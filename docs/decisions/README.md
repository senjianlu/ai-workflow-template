# 决策记录

<!-- TEMPLATE: 约定通用,无需裁剪。存量项目迁移时,老 CLAUDE.md 中
"已确认决策"逐条搬为记录。项目可在本文件末尾追加自己的决策索引。 -->

一事一文,分两个系列,编号互不相干:

| 系列 | 文件名 | 归属 |
|---|---|---|
| 模板决策 | `tNNNN-<slug>.md`(如 `t0003-…`) | 由模板(ai-workflow-template)维护,随模板升级整体替换;派生项目不新增、不修改 |
| 项目决策 | `NNNN-<slug>.md`(自 0001 递增) | 属于项目自己;模板升级不触碰 |

模板仓库自身只新增 `t` 系列(从现有最大编号续编);派生项目只新增纯数字系列。
受管文件(CLAUDE.md、`.ai-workflow/` 脚本等)引用的都是 `t` 系列,所以派生项目
须保留它们。

轻量四段(`<编号>` 为 `tNNNN` 或 `NNNN`):

```markdown
# <编号>:<决定一句话>

- 日期:<yyyy-mm-dd>
- 背景:为什么面临选择
- 决定:选了什么(含被否掉的主要备选)
- 影响:约束了什么,谁要跟着改
```

已确认的决策不再复议;要推翻就新增一条记录声明取代旧决策,并在旧
文件顶部加"已被 <编号> 取代"——不删除历史。

## 沿革:旧编号对应

模板 1.4.0 之前,模板决策用纯数字 `0001` ~ `0013`,与派生项目自编的决策撞号
(见 [t0014](t0014-template-decision-namespace.md))。1.4.0 起改为同号加 `t`:
`0001` → `t0001`,……,`0013` → `t0013`。模板仓库 `.ai/` 下的历史任务记录与
CHANGELOG 1.3.0 及更早条目不回改,其中的 `docs/decisions/00NN` 即今
`docs/decisions/t00NN`。

1.4.0 之前创建的派生项目,自有决策可能从 `0013` 起编:升级后保持原号不变,
前面的空号不补。
